# Breathe Reset

A guided breathing exercise web app for nervous system regulation.

## Features
- **4-7-8 Breathing** — Activates the parasympathetic nervous system
- **Box Breathing** — 4-phase equal cycle, used for stress/focus
- **Calm Breathing** — Slow 5-5 pattern for deep relaxation

## Usage
Open `index.html` in any modern browser. No build step required.

## Structure
```
breathe-reset/
├── index.html    — App shell & markup
├── style.css     — Deep-space dark theme, animations
├── script.js     — Breathing engine, state management
├── assets/       — (reserved for future icons/sounds)
└── README.md
```

## Tech
- Pure HTML / CSS / JavaScript — zero dependencies
- Google Fonts: DM Serif Display + DM Sans (loaded via CDN)
- CSS custom properties for full theming
- SVG progress arc for phase visualization
