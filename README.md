# Breathe Reset 🫁

**Breathe Reset** is a simple guided breathing web app designed to help regulate the nervous system using scientifically supported breathing techniques.

This project was built primarily **for my personal use** to practice daily breathing exercises that help with relaxation, stress reduction, and mental clarity.

However, the app is open-source so others can also benefit from these breathing techniques.

---

## 🌿 Features

* Guided breathing exercises with visual timers
* Animated breathing circle for inhale / hold / exhale
* Multiple breathing techniques
* Clean, minimal and calming UI
* Responsive design for desktop and mobile
* No frameworks — built with pure HTML, CSS, and JavaScript

---

## 🧘 Breathing Techniques Included

### 1. 4-7-8 Breathing

A popular relaxation technique that helps calm the nervous system.

* Inhale for **4 seconds**
* Hold for **7 seconds**
* Exhale for **8 seconds**

Often used to reduce anxiety and improve sleep.

---

### 2. Box Breathing (4-4-4-4)

A technique used by athletes and even military personnel to improve focus and control breathing.

* Inhale **4 seconds**
* Hold **4 seconds**
* Exhale **4 seconds**
* Hold **4 seconds**

---

### 3. Calm Breathing (5-5)

A simple balanced breathing exercise.

* Inhale **5 seconds**
* Exhale **5 seconds**

Useful for daily relaxation and meditation.
